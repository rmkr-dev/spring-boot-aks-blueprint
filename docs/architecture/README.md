# Architecture docs

This folder describes the Spring Boot + AKS blueprint **as it exists in the tree**.

| File | Role |
| --- | --- |
| [architecture.md](architecture.md) | Current-state architecture narrative |
| [architecture-diagram.md](architecture-diagram.md) | Mermaid diagram (filled when components exist) |
| [network-diagram.md](network-diagram.md) | Network view (implemented vs AKS target) |

## What belongs here

- A short current-state narrative that matches the repo
- Diagrams that explain that narrative
- Links to ADRs in [`docs/decisions/`](../decisions/README.md)

## What does not belong here

- Roadmaps disguised as current state
- Diagrams of a live AKS cluster that was never applied from this repo
- Vendor or company names that are not part of the software
